Privacy policy

Last updated: 25 October 2026.

Torn Atlas is a YouTube channel. The "Torn Atlas" Google app is an internal tool used only by the channel's owner to publish the channel's own videos and read the channel's own statistics. It is not offered to the public and no other person signs in to it.

What the app accesses

  • YouTube Data API (scope youtube): upload, update, schedule and delete videos on the Torn Atlas channel.
  • YouTube Analytics API (scope yt-analytics.readonly): read view, watch-time and retention statistics of the Torn Atlas channel's own videos.

What the app stores

One OAuth refresh token for the Torn Atlas channel, stored as an encrypted secret in a private GitHub repository, and aggregate statistics about the channel's own videos. The app does not collect, store or share personal data of viewers or of any other Google user, and does not sell or transfer any data.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. YouTube API data is also subject to the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Contact

Through the Torn Atlas YouTube channel: youtube.com/@tornatlasgeo.
